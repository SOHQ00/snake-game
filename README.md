# 🐍 Snake Game

Um jogo clássico da **Cobrinha (Snake)** desenvolvido com **HTML, CSS e JavaScript puro**.
Um projeto simples, leve e divertido para rodar diretamente no navegador. 🎮

## 📌 Sobre o projeto

Este projeto recria o famoso jogo Snake, onde o jogador controla uma cobrinha que deve comer frutas 🍎 para crescer e acumular pontos.

O objetivo é sobreviver o maior tempo possível sem colidir com as paredes ou com o próprio corpo. 🚀

## ✨ Funcionalidades

✅ Movimento da cobrinha com teclado
✅ Controle usando as setas direcionais ⬆️⬇️⬅️➡️
✅ Geração aleatória de frutas 🍒
✅ Crescimento da cobrinha ao comer frutas
✅ Sistema de pontuação 🏆
✅ Detecção de colisões 💥
✅ Tela de Game Over
✅ Botão para reiniciar o jogo 🔄
✅ Interface simples e responsiva 📱💻

## 🛠️ Tecnologias utilizadas

* 🟧 HTML5
* 🎨 CSS3
* 🟨 JavaScript (Vanilla JS)

* Evite encostar no próprio corpo.
